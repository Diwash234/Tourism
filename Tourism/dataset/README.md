# Nepal city travel dataset

Files:

- `nepal_cities_200.csv`: machine-readable table of ~200 major cities/municipalities across Nepal's 7 provinces (Bagmati 40, Koshi 32, Madhesh 32, Lumbini 35, Gandaki 25, Karnali 18, Sudurpashchim 18) with district, approximate 2021 census population, type, notes.
The itinerary API uses only city, district, and province names from the CSV to normalize searches. Actual itinerary stops and service recommendations are built from approved database records.
