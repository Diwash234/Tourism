# DEPRECATED - use ../Tourism/requirements.txt
#
# This file used to be a hand-curated 22-package subset of
# requirements.txt, and the two silently drifted apart. That drift has
# already caused two production outages:
#
#   * `twilio` was missing here, so every SMS send raised ImportError.
#   * `bcrypt` was missing here, so after the password hasher moved to
#     bcrypt every sign-in and sign-up failed on any environment that
#     installed this file instead of the pinned one.
#
# Rather than maintain a second list, delegate to the single canonical,
# fully pinned dependency set. `pip install -r requirement.txt` therefore
# installs exactly what CI, Docker and local setup install, so there is no
# longer anything to drift.
#
# Note: the ML microservice has its own requirements.txt
# (../ml_service/requirements.txt) and is NOT installed from this file.
-r requirements.txt
